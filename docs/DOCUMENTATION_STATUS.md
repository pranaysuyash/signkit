## 🔄 MAINTENANCE

### When to Update This Doc
- When launching new features
- When completing major milestones
- When creating new strategy docs
- Monthly review recommended

### How to Mark Docs Obsolete
Add this header to the top:
```markdown
> **⚠️ OBSOLETE - [Date]**  
> This document was created for [purpose] ([original date]).  
> **[What changed]**  
> For current status, see: `[current doc path]`  
> Keeping for historical reference only.
```

### How to Mark Docs Complete
Add this header to the top:
```markdown
> **✅ COMPLETED - [Date]**  
> [What was completed and when]  
> Keeping for reference.
```
