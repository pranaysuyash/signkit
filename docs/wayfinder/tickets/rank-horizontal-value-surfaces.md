# Rank horizontal value surfaces without generic-PDF drift

## Question

Which horizontal capabilities create durable, repeatable value around the local document-execution core, and which apparently adjacent capabilities would dilute the product into a generic PDF or identity suite?

## Scope additions

Assess template governance, controlled batch execution, audit/receipt retention, account/entitlement operations, and integration adapters as distinct value surfaces. Use the repository's bulk-signing and certificate research as historical input only, and separate valuable but high-risk certificate work from ordinary image-signature workflows.
