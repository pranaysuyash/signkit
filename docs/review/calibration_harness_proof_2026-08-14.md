## What was integrated

The preserved parallel `calibration/` slice now provides one dependency-light
canonical harness for the two detector confidence streams. It includes:

- lazy PDF and image detector adapters;
- manifest validation with detector type, split, IoU threshold, and PDF page-index checks;
- one-to-one candidate/ground-truth IoU matching, including optional PDF page matching;
- ECE, reliability, ROC AUC, PR AUC, recall@k, and threshold metrics;
- pure-numpy isotonic and Platt calibrators;
- an explicit warning when metrics are not held out by a dedicated test split;
- a CLI and deterministic synthetic self-test.
